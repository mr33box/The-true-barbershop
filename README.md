# ✂️ The True Barbershop Website

This project is a custom website I built for one of my clients, **The True Barbershop**.
The goal was to create a clean, modern, and professional online presence that reflects the quality and style of their work.

I focused on a minimal black & white design, smooth animations, and a strong visual experience — especially with the hero section and gallery showcasing their cuts.

🌐 **Live Website:**
http://southerncateringcafe.xo.je

---

### 💡 About the Project

This website highlights:

* The barbershop’s services and identity
* A dynamic and modern gallery
* A smooth, responsive design across all devices
